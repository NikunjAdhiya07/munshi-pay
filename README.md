# Munshi Pay

Payroll and salary consultancy platform.

The execution board is generated from `board/state.json`:

- [Execution board](EXECUTION_BOARD.md)
- [Status](docs/status.md)
- [Plan](docs/plan.md)
- [Decisions](docs/decisions.md)

```bash
npm test
npm run board
npm run board:check
```

Edit tasks only in `board/state.json`. Edit skills only in `skills/`. Do not edit the generated board by hand.

Agent instructions: [AGENTS.md](AGENTS.md).
