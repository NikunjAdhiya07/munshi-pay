# UI and UX

The working rules are the skills:

- `skills/payroll-ui-ux`
- `skills/responsive-mobile-ux`
- `skills/payroll-domain-ux`
- `skills/accessibility`

## Direction

Munshi Pay should look like a tool a payroll consultant can use all day. Warm paper background, ink text, one slate-blue accent, compact tables, tabular figures, and status words. Tokens are in `skills/payroll-ui-ux/tokens.md` (DEC-006).

## References

These were read for principles and were not copied into the repo:

- [UIX lucid-ui](https://github.com/Deepractice/UIX): anti-generic color, spacing scale, borders instead of decoration
- [saas-ui-skills](https://github.com/param087/saas-ui-skills): production states for tables, forms, dialogs, and navigation
- [cursor-designer](https://github.com/spencergoldade/cursor-designer): heuristics, shallow navigation, WCAG as a default, stable labels

## Not in the product yet

No screens exist. The shell, employee list, and dashboard are later phases. Dashboards will show aggregates from persisted runs and will label any non-real data.
