# Changelog

## 2026-10-06

- Added the engineering operating system: task state, generated execution board, skills for Cursor and Claude Code, and the baseline architecture decisions.
- Added the Next.js application shell. The home page states that payroll features are not available yet. No payroll figures are shown.

## 2026-10-07

- Audited the execution board against the reference and the code. Removed duplicate and out-of-scope tasks, split large ones, added the missing ones, and moved every task into a module phase. See DEC-012.
- T-032: Every workspace page now checks the view right for its menu, and a role without it is sent to the dashboard with a message before any data is read. The side menu leaves out pages the role cannot open, and the dashboard leaves out each section, with the figures behind it, that the role cannot view. Switching company needs membership, and a session whose company is no longer a membership company goes back to Select Company. Leave encashment now checks that the employee belongs to the company and is audited, and a line adjustment looks the employee up inside the company. A test fails if a new page or a new action is added without a check.
- S-008: The new employee form takes first, middle, and last name, gender (default male), join date, salary base, department, designation, mobile, email, and PF and ESI deduction (both on by default). The code is the next one in the company, shown read-only and assigned on save, and a used code is refused. The profile tab adds addresses, PF and ESI join and leave dates and reasons, ESI dispensary, and the bonus, leave encashment, and ABRY flags. Aadhaar, PAN, and account numbers show masked and keep their saved value unless changed. The flags and dates are recorded only. Photo upload waits for file storage (T-216). See DEC-019.
- S-015: Added the Set percentage page. Gross and CTC categories have separate lists with add, edit, and guarded delete. Basic plus DA above 100 is refused, and a category that salary rows use cannot be deleted. The category form moved off Lists and rules. The CTC flag still has no effect on the split until T-217.
- S-017: Added the Misc. entry page for departments, designations, and banks, with edit and guarded delete. Employee forms now pick these values from the lists and the server refuses a value that is not listed. Renaming an entry updates the employees who carry it. The lookup panel moved off Lists and rules.
- S-024: Added the Shift master page with the second in and out times, present and half-day hours, night-off shift, and night-duty punch, plus edit and guarded delete. The employee Other tab picks a shift from the list. No shift field affects the muster or pay yet.
- S-034: Added the Leave policy page that lists policies by pay cadre, leave name, duration, and ratio, with edit and guarded delete. The policy form moved off the Leave page. Renaming a policy updates the register and encashment rows that carry the name, and delete is refused while they use it. Duration and ratio are recorded only, and nothing calculates leave.
- S-039: The report catalog is grouped as the reference list, with the source, run status, row count, and data origin of each report. Every report now downloads its own rows. The CSV uses plain rupees instead of a currency symbol, and text that starts with a formula character is stored as text. Reports and downloads check the reports view right. A month filter overrides the header month for one report, and the salary register can show a payment date as typed. Type and Style filters are not built because their values were not captured.
- T-100: The salary slip now shows the company name and state, month, employee code, designation, department, payment method, and paid days, with a labeled row for any typed adjustment. It has an A4 print layout with one slip per page. Salary slips can print all slips or only the ticked employees, and the browser print dialog saves a PDF. A server-made PDF, company address, slip style, and the locked-run snapshot are still open. The side menu now marks only the closest match as the current page.
- Corrected the traceability table in `docs/munshipay-analysis.md`. Most rows said IMPLEMENTED where the code covers only part of the screen.
